# 会社のファイル一覧

有料noteを売る、小さな会社の設計図です。

- `会社の方針.md` — 誰に売るか、いくらで売るか、絶対にやらないこと、文章の書き方のルール
- `役割_1_企画係.md` — 何を売るか決める、次の商品を決める
- `役割_2_調べる係.md` — テーマについて調べる
- `役割_3_書く係.md` — 記事を書く
- `役割_4_売る係.md` — 値段をつける、売り文句を作る、売れ行きを見る

## 仕事の流れ

企画係 → 調べる係 → 書く係 → 売る係 → (売れた記録)企画係へ戻る

## 使い方

それぞれの係の仕事をするときは、まず「会社の方針.md」と、自分の係のファイルを読んでから始めてください。
同じ質を保つためのルールです。
